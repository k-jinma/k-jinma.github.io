# 研究室について

## 教員紹介

**神馬 一博（Kazuhiro Jinma）**
人間環境大学 総合環境学部 環境情報学科 准教授

### 専門分野

- ソフトウェアアーキテクチャ設計（DDD、マイクロサービス、イベント駆動）
- バックエンド開発
- フロントエンド工学
- 生成AI応用とAI支援開発プロセス
- データベース設計・データモデリング
- プログラミング教育・技術標準化

### 主な所属・活動

- Java Community Process
- Java in Education
- 情報処理学会
- 文部科学省「生成AI人材育成事業」実施委員
- 若年者ものづくり競技大会 審査員

### 経歴概要

20年以上にわたるソフトウェア開発と教育の実務経験を持つ。学校でのICT教育マネジメント、企業でのシステム開発を経て、現在は大学でIT人材育成に取り組む。文部科学省・厚生労働省の委託事業において実施委員を歴任し、産学官連携活動にも積極的に参画。

## 配属を希望する学生へ

### こんな学生を歓迎します

- ソフトウェア開発に興味がある（経験は問いません）
- 技術が社会や教育に与える影響を考えたい
- 新しい技術（生成AI、クラウド等）にチャレンジしたい
- 実践的な開発スキルを身につけたい
- オープンソースやコミュニティ活動に関心がある

### 研究室での学び

**実践的なスキル習得**
実際にコードを書き、システムを作ることで学びます

**技術の本質理解**
なぜそう設計するのか、背景にある思想を考えます

**社会との接点**
技術が社会や教育に与える影響を常に意識します

**コミュニティ参加**
開発者コミュニティとの交流を通じて視野を広げます

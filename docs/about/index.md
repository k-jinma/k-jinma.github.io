# 研究室について

## ソフトウェア開発と教育の融合で探る、技術と社会の新たな関係性

当研究室では、ソフトウェア開発技術が社会や教育にもたらす変革を多角的に探究しています。プログラミング言語やフレームワークの進化、開発手法の変遷、そしてそれらが人々の学びや働き方、社会システムにどのような影響を与えるのかを研究テーマとしています。

近年は、「生成AIがもたらすソフトウェア開発の構造変化」を主題に据え、AI支援による開発プロセスの変容、プログラミング教育への影響、そして開発者に求められるスキルセットの再定義について、実践的な開発経験と教育現場での観察を通して考察しています。その延長として、イベント駆動型アーキテクチャ（Event-Driven Architecture）と生成AIの統合による、新しいシステム設計手法の可能性も探っています。

また、オープン教育リソース（OER）の開発や、プログラミング技術標準化が教育に与える影響、さらには実務と教育のギャップを埋めるカリキュラム設計の研究にも継続的に取り組んでいます。これらの研究活動を通じ、技術の進化が社会や教育にもたらす可能性を明らかにするとともに、持続可能で創造的なソフトウェア開発文化の形成に貢献することを目指しています。

---

## 主な研究テーマ

### 生成AIとソフトウェア開発
AI支援開発ツールが開発プロセスに与える影響、開発者の役割変化、教育への応用

### ソフトウェアアーキテクチャと社会システム
設計思想の進化、イベント駆動型システム、マイクロサービスが組織や社会に与える影響

### プログラミング教育の未来
技術進化に対応した教育手法、OER開発、実務と教育の連携モデル

### 技術標準化と開発文化
プログラミング言語・API設計の標準化プロセス、開発コミュニティの形成と発展
